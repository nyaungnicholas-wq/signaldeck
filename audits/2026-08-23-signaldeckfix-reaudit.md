## Refuted

One agent finding did not survive checking: **TraderHud Daemon is registered and Running**
(Get-ScheduledTask, matching the 2026-08-18 memory record). The underlying observation, that
install-windows-tasks.ps1 silently skips any plist whose ProgramArguments is not a shell
script, is true, and install-sibling-tasks.ps1 is the deliberate workaround.

## Suggested order

A12 first: it undermines the integrity of the chain every other pre-registration claim rests
on, including the forward test filed today. Then A9 and A10, which put the disaster-recovery
artifact and retention at risk. Then A11, A13, A14 and A17, which govern what gets published.

A23 requires a prereg amendment rather than a code change and should be decided before the
forward-test window opens, after which the population stops being amendable without suspicion.
