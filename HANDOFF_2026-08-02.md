## TRIED, DIDN'T WORK

- **Graceful shutdown (item 7) cannot be demonstrated from this shell.** The handler is
  real — `signal.NotifyContext(ctx, os.Interrupt, syscall.SIGTERM)` at
  `daemon/cmd/signaldeckd/main.go:67` — but Windows refuses non-forced `taskkill` on this
  process (`This process can only be terminated forcefully`), so no real signal can be
  delivered. **Recorded as inferred, never as verified.** To close it: launch the daemon in
  a console you own and send a genuine Ctrl+C, or run it as a service that receives a stop.
- **First `git archive HEAD` build failed** with `revision_stamp=""`. My error, not a
  defect: `ops/signaldeck-ctl.sh:build_from_head` stamps the commit via
  `-ldflags "-X …/internal/lineage.ldflagsRev=$rev"` precisely because `git archive` drops
  `.git`. **Use that ldflags stamp or the daemon will refuse to start, correctly.**
- **A worker's whole-file rewrite of `selfaudit.go` was rejected.** It compiled and passed
  the tests while adding a UTF-8 BOM and corrupting every non-ASCII character, including
  inside user-facing detail strings. Reapplied by hand. **Diff worker output for encoding,
  not only for logic — the test suite will not catch mojibake.**
- **A `longctx` worker fed the 390 KB `/api/quality` dump ignored the brief entirely** and
  returned an unrelated trading hypothesis. Pre-filter large JSON before delegating.
- **The `best` lane degraded on every call** (gemini-3.1-pro 429, gemini-3-flash 503 →
  devstral). Check the `via` line; it explains bad output.

### omni.ps1 invocation — four ways I lost time, so you don't

1. **`-File` with MULTIPLE files does not work via `powershell -File`.** Space-separated,
   files 2..n bind to the next positional parameter and get tried as *model names*
   (`track-record.json … 404`). Comma-separated arrives as one literal token
   (`No such file: a.json,b.json,…`). **Fix: concatenate the inputs into one bundle file and
   pass a single `-File`.** Same arg re-parsing footgun already documented for `-Verify`.
2. **Don't run a worker in the foreground.** The Bash tool caps at 10 minutes and silently
   clamps a larger timeout, killing the call. Run workers with `run_in_background`.
3. **`-Task reason` is deepseek-r1:32b locally** — a 32B reasoning model on a 64 KB input
   times out. Use `-Task best` (gateway-first) for analysis over large payloads.
4. **Pre-filter before delegating.** A 390 KB payload made a worker abandon the brief
   entirely. Downsampling `model-evolution` to daily last-values cut 67 KB → 21 KB with no
   loss of the trajectory, and that call succeeded.
