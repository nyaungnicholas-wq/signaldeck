## 3. Wording rules and how they were enforced

The rules were not left to judgement. `tools/check_strategy_deck.py` runs against the
deck and exits non-zero on a violation. It enforces:

| Rule | Check |
|---|---|
| No hype, no self-praise, no "moat" language | Literal ban on *moat*, *world-class*, *best-in-class*, *revolutionary*, *cutting-edge*, *seamless*, *state-of-the-art*, *industry-leading*, *unlock*, *game-chang* |
| No "guaranteed", no "verified" unless proven | Literal ban on *guaranteed*, *verified*, *proven* — the last because it is the same claim in a different word |
| No number without provenance | Every numeric token in the deck must appear in an allowlist of figures measured during P6. A fabricated statistic fails the build; a grep for hype words would not have caught one |
| No interval verdict | Regex ban on *confidence interval below*, *interval below the*, *significant … skill*, *statistically significant* |
| No mixing historical and live without labels | Both `HISTORICAL` and `LIVE` must appear as explicit labels |
| Every number carries a status | The status vocabulary — BUILT AND IN FORCE, BUILT BUT NOT IN FORCE, NOT BUILT, RETIRED, PENDING — must all appear |
| Structure | All fourteen section headings must be present, in order |

The number allowlist is the load-bearing one. The deck's first draft was generated by
a worker model against a brief, and the failure mode that matters for a document whose
purpose is containing no false claims is an invented statistic, which no keyword check
detects.

## 5. A defect this phase introduced, and how it is handled

Remediation phases P1 through P5 were landing in the repository *while* P6 and P7 were
being written. Between the first draft of P6 §1 and the filing of this document,
`universe_membership` went from 0 rows to 1,854,228, the kill switch went from unwired
to wired and tested, `delisted_at` stamps went from 16 to 716, and nine proof artefacts
appeared in `proofs/`.

Three times, a sentence stating that an artefact did not exist was true when written
and false an hour later. Four consequences, all recorded rather than smoothed over:

1. Rows of `proofs/P6_GOVERNANCE_CLEANUP.md` §1 are **amended in place** with
   strikethrough and a re-measurement, not silently rewritten. A status table that
   quietly updates itself is the failure mode P6 exists to remove.
2. Every phase-status statement in the deck carries an explicit measurement date and
   tells the reader to read `proofs/` directly rather than trust the snapshot.
3. Where the platform changed, the new state was **re-measured against the database
   and the source tree**, never inherited from another document's claim about it.
4. The recurrence is now **guarded rather than promised**. `tools/check_strategy_deck.py`
   fails if any document claims a `proofs/` artefact is missing while that file
   exists. The guard was self-tested by appending a false absence claim, confirming a
   non-zero exit, and restoring the file.

The survivorship row is the clearest case of (3). The final state is neither the
"open" of `ALPHA_WORKFLOW.md` §B2 nor the "closed" that later documents narrated: P3A
closes 2019–2022 and quantifies a 2023–2025 residual, because the upstream endpoint
under-reports recent years and the live detector only began watching in 2026. The deck
states the window, not the verdict.
